Temat: Zapytania - strukturalny język zapytań.
SQL zapewnia obsługe:
- zapytan - wyszukiwanie danych w bazie
- operowania danymi - wstawianie, modyfikowanie i usuwanie
- definiowania danych - dodawanie do bazy danych nowych tabel
- sterowania danymi - ochrona przed niepowolanym dostepem.

DELETE usuwa dane lub rekordy, a DROP usuwa bazy i tabele.

Operatory:
rowny =
nierowny <>
mniejszy <
wiekszy >
mniejszy lub rowny <=
wiekszy lub rowny >=

Wampserver - do baz danych zamiast XAMPPA.

Przyklady:
SELECT * FROM `auto` WHERE cena > 5000;
SELECT * FROM `auto` WHERE cena > 40000 AND cena < 50000;
SELECT * FROM `auto` WHERE cena >= 40000 AND cena <= 50000;
